Glowgrid design system

Themes

One engine and one set of components, recolored and re-lit per theme. Every theme keeps the same rules: light comes from inside the scene, art pixels stay hard, only the glow is soft.

Ember

Dark cavern, binary embers, magenta crystal, acid pool. The default.

data-theme="ember"

Forge

Glowing cog over an anvil, molten pool, frost shards for contrast.

data-theme="forge"

Frost

Ice cavern, frost lattice, icicles, frozen pool, small warm embers.

data-theme="frost"
